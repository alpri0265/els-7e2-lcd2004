# Программные лимиты: инструкция для прошивки PlatformIO

Эта инструкция соответствует коду **`src/main.cpp`** (сборка **PlatformIO**, `platformio.ini`).  
Отдельный проект **STM32Cube / HAL** в каталоге `ELS-7e2-lcd2004/` может отличаться по меню и условиям обучения — для него смотрите комментарии в `Core/Src/els_limits.c`.

---

## 1. Что это за кнопки

Четыре входа обучения (в коде: `TEACH_LIMIT_*`, активный уровень **LOW** с подтяжкой вверх):

| Сигнал в коде | Пин MCU | Назначение |
|---------------|---------|------------|
| Z LEFT        | **PA11** | Запомнить **левый** программный предел по оси **Z** |
| Z RIGHT       | **PA10** | Запомнить **правый** предел по **Z** |
| X FRONT       | **PA9**  | Запомнить **передний** предел по **X** |
| X REAR        | **PA8**  | Запомнить **задний** предел по **X** |

Это **не** разрезание цепи «как у концевика»: нажатие **записывает текущую позицию в шагах** (`motor_z_steps` / `motor_x_steps`) как границу. Повторное нажатие по той же кнопке **снимает** этот лимит.

Индикация: **LED_LIM_*** (`PG12`…`PG15`) — в этой прошивке лимит «включён» = на выводе **HIGH** (светится, если светодиод включён анодом к пину как обычно).

---

## 2. Джойстик (частая причина «не записывается»)

В **`src/main.cpp`** оси привязаны так:

- **Влево / вправо** — ось **Z** (ручной поджим по Z).
- **Вверх / вниз** — ось **X**.

Перед записью лимита прошивка требует «нейтраль» по соответствующей оси:

- Чтобы сработали кнопки **Z LEFT / Z RIGHT**: рычаг **не** должен быть нажат **влево и не вправо** (ось Z в покое).
- Чтобы сработали **X FRONT / X REAR**: рычаг **не** должен быть нажат **вверх и не вниз** (ось X в покое).

Если держать не ту ось (например, думая что Z — это вверх/вниз), обучение **молча не выполнится**.

Обучение кнопками — **только в MAN**, як у Arduino `Menu.ino` (див. п. 5).

---

## 3. Аппаратный стоп MECH

Если сработала цепь **LIM_MECH_1** (**PD1**) или **LIM_MECH_2** (**PD14**) (активный **LOW**), обучение лимитов **блокируется**, пока линия в состоянии аварии. Сначала устраните причину и отпустите цепь.

---

## 4. Как нажимать кнопку обучения

- После стабилизации состояния кнопок **30 ms** фиксируется «короткое появление» нажатия (**фронт**): нужно **отпустить** кнопку перед следующим событием, иначе второй раз за один удержанный клик не сработает.
- Длинное удержание без отпускания даёт один срабатывающий фронт при первом нажатии.

---

## 5. Обучение как в Arduino `Menu.ino` (`Limit_*_Pressed`)

- Только подрежим **MAN** и режимы **FEED / aFEED / THREAD / CONE / SPHERE**.
- Зазор до вже заданого протилежного ліміту: **`(MIN_RAPID_MOTION − MAX_RAPID_MOTION) * McSTEP_Z * 2`** → **660** мікрокроків при `McSTEP_Z = 2` (для X у скетчі використано той самий числовий зазор). Ближче — запис **не відбувається** (без біпа), як на Mega-скетчі.
- Під час руху шаговиків з джойстика або циклу **aFEED** кнопки обучення не обробляються.

---

## 6. Звук и «ничего не произошло»

При успешной записи/снятии вызывается **короткий бип** (`beeperTrigger`). Если бузер не слышен, смотрите **LED** соответствующего лимита.

Тихий отказ возможен, если: **джойстик не в нейтрали по нужной оси**, сработал **MECH**, или кнопка не прошла дребезг/не было «отпускания» для нового фронта.

---

## 7. Режимы INT / EXT на дисплее

Для внутренней/внешней подачи прошивка может требовать **пару лимитов по Z** или **пару по X** и показывать сообщения вроде «упоры не заданы» / «установите суппорт…» — это уже **логика режима**, а не блокировка самих кнопок обучения. Вернув тумблер в **MAN**, можно снова работать без этих проверок (как в оригинальном скетче).

---

## 8. Краткий порядок для оператора (PlatformIO)

1. Тумблер подрежима — **MAN**, режим з дозволеного списку (див. п. 5).
2. Убедиться, что **MECH** не активен.
3. Подвести суппорт; для **Z**-лимитов отпустить рычаг **влево/вправо**; для **X** — отпустить **вверх/вниз**.
4. Кратко нажать и **отпустить** нужную кнопку лимита — бип + LED.
5. Для другого кінця осі: від’їхати далі **660** мікрокроків від протилежного ліміту (див. п. 5), інакше запис не спрацює.
6. Повторное нажатие по той же кнопке **снимает** лимит.
